# 股票交易系统（本地 Web）

基于 `../trading-system/` 规则库实现的**交易决策与执行**工具（非荐股、非自动下单）。

## 功能模块

| 页面 | 对应规则文档 |
| --- | --- |
| 总览 | 标准流程、今日环境摘要 |
| 市场环境 | `01_市场环境判断.md` — 五维 0–10 评分 |
| 观察池 | `02_选股体系.md` — 20 分选股评分 |
| 个股详情 | 日 K + MA5/20/30 + 成交量 + MACD（从观察池点击进入） |
| 买入计划 | `03_买入规则.md` — 计划表单 + 买入检查表 |
| 仓位计算 | `05_仓位与风险控制.md` — 按止损算可买金额 |
| 持仓 | `04_卖出规则.md` — 持仓与卖出信号速查 |
| 交易复盘 | `06_复盘模板.md` — 归类与统计 |
| 每日清单 | `07_每日交易清单.md` — 盘前/盘中/盘后勾选 |
| 规则库 | 核心原则速查 |

- **实时行情**：东方财富为主，失败时自动回退腾讯 `qt.gtimg.cn`（开发环境经 Vite 代理 `/api/em`、`/api/qt`）
- **个股图表**：腾讯前复权日 K（`/api/qq`），含 MA5/20/30 与 MACD(12,26,9)
- **本地记录**：交易计划、评分、复盘等仍保存在浏览器 `localStorage`

开发模式下通过 Vite 代理访问行情接口；`npm run preview` 同样已配置代理。

## 启动

```bash
cd trading-app
npm install
npm run dev
```

浏览器打开终端提示的地址（一般为 http://localhost:5173）。

## 建议使用顺序

1. **盘前**：市场环境评分 → 每日清单（盘前）
2. **选股**：观察池打分，≥16 进入重点观察；点击代码/名称查看 K 线与 MACD
3. **计划**：出现买点后填写买入计划并通过检查表
4. **下单前**：仓位计算器确认金额与单票上限
5. **持仓**：记录持仓，对照卖出规则
6. **盘后**：每日清单（盘后）+ 平仓后写入交易复盘

## 系统定位

- ✅ 环境 → 模式 → 计划 → 仓位 → 执行 → 复盘
- ❌ 不提供自动下单、荐股；历史回测与分钟 K 可后续扩展

后续可接入行情 API 做观察池扫描，见 `trading-system/交易系统设计方案.md` 第 13 节。
