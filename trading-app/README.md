# 股票交易系统（本地 Web）

基于 `../trading-system/` 规则库实现的**交易决策与执行**工具（非荐股、非自动下单）。

## 功能模块

| 页面 | 对应规则文档 |
| --- | --- |
| 总览 | 标准流程、今日环境摘要、**JSON 数据备份** |
| 市场环境 | `01_市场环境判断.md` — 五维 0–10 评分 + AI 智能评分 |
| 观察池 | `02_选股体系.md` — 20 分选股评分、规则扫描、一键买入 |
| 自选股 | 独立跟踪，记录加入时价格与时间 |
| 个股详情 | 日 / 周 / 月 K + MA5/20/30 + 成交量 + MACD |
| 买入计划 | `03_买入规则.md` — 计划表单 + 买入检查表 |
| 仓位计算 | `05_仓位与风险控制.md` — 按止损算可买金额 |
| 持仓 | `04_卖出规则.md` — 持仓与规则建议（加仓/减仓/清仓） |
| 历史练习 | `02_选股体系.md` — 历史日 K 观察池判断与规则比对 |
| 交易复盘 | `06_复盘模板.md` — 归类与统计 |
| 每日清单 | `07_每日交易清单.md` — 盘前/盘中/盘后勾选 |
| 规则库 | 核心原则速查 |

## 数据与行情

- **实时行情**：东方财富为主，失败时自动回退腾讯 `qt.gtimg.cn`（开发环境经 Vite 代理 `/api/em`、`/api/qt`）
- **个股图表**：腾讯前复权 K 线（`/api/qq`），含 MA5/20/30 与 MACD(12,26,9)；5 分钟 TTL 缓存，并发请求自动合并
- **本地记录**：计划、评分、持仓、复盘、练习等保存在浏览器 `localStorage`
- **备份恢复**：总览页导出 / 导入 JSON（见 `src/lib/data-backup.ts`）

开发模式下通过 Vite 代理访问行情接口；`npm run preview` 同样已配置代理。

## 技术栈

- React 19 + TypeScript + Vite 8
- `lightweight-charts` 图表；路由与图表分包懒加载
- 行情 / 指数 / App 数据分 store（`quotes-store`、`market-store`、`app-store`）细粒度订阅


## 建议使用顺序

1. **盘前**：市场环境评分 → 每日清单（盘前）
2. **选股**：观察池打分或规则扫描，≥16 进入重点观察；点击代码/名称查看 K 线与 MACD
3. **计划**：出现买点后填写买入计划并通过检查表
4. **下单前**：仓位计算器确认金额与单票上限
5. **持仓**：记录持仓，查看规则建议（加仓/减仓/清仓）
6. **练习**（可选）：历史练习巩固选股规则
7. **盘后**：每日清单（盘后）+ 平仓后写入交易复盘
8. **定期**：总览页导出 JSON 备份

## 系统定位

- ✅ 环境 → 模式 → 计划 → 仓位 → 执行 → 复盘
- ❌ 不提供自动下单、荐股

观察池规则扫描已内置（趋势 / 情绪 / ETF），数据源为新浪活跃股列表 + 本地 K 线规则引擎。
