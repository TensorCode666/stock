# 仓位与风险控制

仓位管理决定你能不能活下来。交易系统的目标不是每次都对，而是在亏损时亏得少，在正确时赚得多。

## 总仓位规则

| 市场环境 | 建议总仓位 |
| --- | --- |
| 空头趋势 | 0% 到 20% |
| 震荡市场 | 20% 到 50% |
| 多头初期 | 40% 到 70% |
| 多头主升 | 60% 到 90% |
| 情绪高潮或牛市后期 | 逐步降仓 |

## 单票仓位规则

- 首次试错仓不超过总资金的10%。
- 普通单票不超过20%。
- 强趋势确认后，单票上限可到30%，但必须有止损。
- 不重仓单一题材、单一股票。
- 同一方向持仓过多时，按一个整体风险看待。

## 加仓规则

只允许盈利加仓，不允许亏损加仓。

允许加仓：

- 买入后股价按预期上涨。
- 回踩不破关键支撑。
- 板块继续走强。
- 趋势确认，量价健康。
- 加仓后仍能定义止损。

禁止加仓：

- 跌破买入逻辑后补仓。
- 为了摊低成本而加仓。
- 情绪退潮期加仓。
- 已经超过单票仓位上限。

## 金字塔式加仓

建议从小到大再到小：

1. 首仓：10%，用于试错。
2. 确认：再加10% 到 15%。
3. 主升：趋势明确后再加10%。
4. 高位：不再加仓，只管理卖出。

加仓后的平均成本不能让你失去止损能力。

## 止损金额控制

每笔交易先定义最大亏损金额。

示例：

- 总资金：100000
- 单笔最大亏损：1% 到 2%，即1000到2000
- 计划止损幅度：5%
- 可买仓位：1000 / 5% = 20000

这意味着该笔交易最多买2万元，而不是凭感觉买。

## 风险红线

- 连续亏损3笔，暂停交易并复盘。
- 单日亏损超过计划上限，停止当日交易。
- 单票破位不止损，禁止加仓。
- 情绪失控时不交易。
- 看不懂时空仓。
