# 每日交易清单

这份清单用于实盘执行。每天只需要按顺序检查，不需要临场凭感觉做决定。

## 盘前

- [ ] 今天是否适合交易？
- [ ] 当前市场是多头、空头还是震荡？
- [ ] 当前情绪周期处于哪个阶段？
- [ ] 今天重点板块是什么？
- [ ] 我的总仓位是否合理？
- [ ] 持仓股是否有风险信号？
- [ ] 观察池中是否有接近买点的标的？
- [ ] 今天是否有明确买入计划？
- [ ] 今天是否有明确卖出计划？

## 买入前

- [ ] 这笔交易属于哪种模式？
- [ ] 是否符合当前市场环境？
- [ ] 是否在观察池内？
- [ ] 买点是否清楚？
- [ ] 止损位是否清楚？
- [ ] 目标位是否清楚？
- [ ] 盈亏比是否合适？
- [ ] 仓位是否低于上限？
- [ ] 如果买错，是否愿意立刻认错？

任意一项没有答案，不买。

## 持仓中

- [ ] 趋势是否仍然存在？
- [ ] 是否跌破关键支撑？
- [ ] 是否出现放量滞涨？
- [ ] 是否弱于板块？
- [ ] 是否达到止盈位置？
- [ ] 是否需要降仓？
- [ ] 是否有情绪化加仓冲动？

## 卖出前

- [ ] 卖出是因为规则，还是因为害怕？
- [ ] 当前是否触发止损？
- [ ] 当前是否触发止盈？
- [ ] 趋势是否破坏？
- [ ] 情绪是否退潮？
- [ ] 是否可以分批处理？

## 盘后

- [ ] 今天是否按计划交易？
- [ ] 有无系统外交易？
- [ ] 有无追高？
- [ ] 有无亏损加仓？
- [ ] 有无止损拖延？
- [ ] 持仓是否需要调整？
- [ ] 观察池是否需要更新？
- [ ] 明天的计划是否已经写好？
