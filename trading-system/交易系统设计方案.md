# 交易系统设计方案

本系统基于 `1_extracted.md` 与 `trading-system/` 规则库整理，目标是把经验型交易方法转成可执行、可复盘、可迭代的交易流程。

## 1. 系统定位

这不是自动交易系统，也不是荐股系统，而是一个“交易决策与执行系统”。

它解决四个问题：

1. 今天能不能交易。
2. 应该做哪种交易模式。
3. 这只股票能不能买、怎么买、买多少。
4. 买入后怎么卖、怎么复盘、怎么优化。

系统核心思想：

- 环境优先：先看大盘和情绪，再看个股。
- 模式优先：不同市场环境使用不同交易模式。
- 风控优先：先定义亏多少，再考虑赚多少。
- 执行优先：买前有计划，买后按计划。
- 复盘优先：每笔交易都必须归类为系统内或系统外。

## 2. 系统总流程

```text
市场环境判断
  ↓
选择交易模式
  ↓
建立观察池
  ↓
等待买点
  ↓
交易前检查
  ↓
仓位计算
  ↓
执行买入
  ↓
持仓管理
  ↓
卖出或止损
  ↓
复盘归档
  ↓
优化规则
```

## 3. 市场环境模块

每天先判断环境，环境不合适时，不选股、不交易。

### 3.1 环境类型

| 环境 | 判断特征 | 应对策略 |
| --- | --- | --- |
| 多头主升 | 指数上行，主线清晰，赚钱效应扩散 | 趋势持股、回踩加仓 |
| 多头初期 | 指数企稳，权重或主线启动 | 低位建仓、分批试错 |
| 震荡市场 | 指数区间波动，板块轮动快 | 高抛低吸、小仓波段 |
| 空头市场 | 指数下行，反弹失败，亏钱效应强 | 空仓或极轻仓 |
| 情绪上升 | 龙头打开空间，题材扩散 | 情绪短线、前排参与 |
| 情绪退潮 | 高标杀跌，跌停增多 | 空仓等待 |

### 3.2 每日环境评分

每项 0 到 2 分，总分 10 分。

| 项目 | 0分 | 1分 | 2分 |
| --- | --- | --- | --- |
| 指数趋势 | 下跌 | 震荡 | 上升 |
| 主线板块 | 无主线 | 轮动快 | 主线清晰 |
| 赚钱效应 | 差 | 一般 | 强 |
| 情绪周期 | 退潮 | 修复 | 主升 |
| 成交量 | 缩量弱 | 平稳 | 放量健康 |

环境结论：

- 8 到 10 分：允许积极交易。
- 5 到 7 分：只做低风险机会。
- 3 到 4 分：轻仓观察。
- 0 到 2 分：空仓。

## 4. 交易模式模块

系统只允许三种主模式，避免什么行情都想做。

### 4.1 趋势股模式

适合：

- 多头初期。
- 多头主升。
- 震荡偏强。

标的要求：

- 板块逻辑清晰。
- 股价在20日线附近或上方。
- 均线多头排列。
- 回调缩量，上涨放量。
- 有清晰支撑位和止损位。

买点：

- 突破后回踩不破。
- 回踩20日线企稳。
- 平台整理后放量突破。
- 三周期共振后的分时确认。

卖点：

- 跌破20日线。
- 放量破位。
- 3天不创新高且走势弱于板块。
- 高位放量滞涨。

### 4.2 情绪短线模式

适合：

- 情绪修复期。
- 情绪启动期。
- 情绪主升期。

标的要求：

- 当前主线题材。
- 前排或龙头。
- 成交活跃。
- 有辨识度。
- 买点不是高潮追高。

买点：

- 分歧转一致。
- 龙头带动板块后前排确认。
- 题材启动早期。

卖点：

- 龙头断板无法修复。
- 高位放量分歧。
- 后排开始大跌。
- 情绪进入高潮或退潮。

### 4.3 ETF / 指数模式

适合：

- 上班族。
- 稳健资金。
- 不想承担个股黑天鹅。
- 长周期低位布局。

买点：

- 指数处于相对底部。
- 行业长期逻辑未破。
- 大跌后分批定投。
- 市场冷淡时逐步建仓。

卖点：

- 牛市高潮。
- 基金热卖。
- 指数远离长期均线。
- 收益达到计划目标后分批退出。

## 5. 选股评分模块

股票进入观察池前打分，总分 20 分。

| 维度 | 分值 | 说明 |
| --- | --- | --- |
| 市场环境 | 0-4 | 当前环境是否支持交易 |
| 板块强度 | 0-4 | 是否属于主线或强势板块 |
| 个股趋势 | 0-4 | 均线、结构、位置是否健康 |
| 量价关系 | 0-3 | 是否上涨放量、回调缩量 |
| 买点清晰度 | 0-3 | 是否能定义买点和止损 |
| 风险收益比 | 0-2 | 上涨空间是否大于下跌风险 |

处理规则：

- 16 到 20 分：重点观察，可等待买点。
- 12 到 15 分：普通观察，只能轻仓。
- 8 到 11 分：只观察，不交易。
- 低于 8 分：剔除。

## 6. 买入决策模块

买入必须满足四个条件：

1. 环境允许。
2. 模式匹配。
3. 买点出现。
4. 风险可控。

### 6.1 买入前表单

```text
交易日期：
标的名称：
交易模式：趋势股 / 情绪短线 / ETF
市场环境评分：
选股评分：
买入理由：
计划买入价：
止损价：
目标价：
计划仓位：
盈亏比：
加仓条件：
卖出条件：
```

### 6.2 禁止买入条件

- 没有止损位。
- 盈亏比小于 2:1。
- 当前情绪退潮。
- 连续大涨后高位追入。
- 个股走势弱于板块。
- 只是因为消息、推荐、感觉而买。
- 买入后不知道错了怎么办。

## 7. 仓位管理模块

仓位由环境和交易质量共同决定。

### 7.1 总仓位

| 环境评分 | 总仓位 |
| --- | --- |
| 8-10 | 60%-90% |
| 5-7 | 20%-50% |
| 3-4 | 0%-20% |
| 0-2 | 0% |

### 7.2 单票仓位

| 交易质量 | 单票仓位 |
| --- | --- |
| 高质量趋势股 | 15%-25% |
| 普通趋势股 | 10%-15% |
| 情绪短线 | 5%-15% |
| ETF分批 | 每次5%-10% |
| 试错交易 | 不超过10% |

### 7.3 单笔亏损控制

单笔最大亏损建议控制在总资金的 1% 到 2%。

仓位计算公式：

```text
可买金额 = 单笔最大可亏金额 / 止损幅度
```

示例：

```text
总资金：100000
单笔最大亏损：1000
止损幅度：5%
可买金额：1000 / 5% = 20000
```

## 8. 加仓模块

只允许盈利加仓，不允许亏损加仓。

允许加仓：

- 买入后走势符合预期。
- 回踩关键支撑不破。
- 板块继续走强。
- 放量突破新高。
- 加仓后仍能承受止损。

禁止加仓：

- 跌破买入逻辑。
- 为摊低成本补仓。
- 情绪退潮。
- 已达到单票仓位上限。

建议加仓结构：

```text
首仓 10%
确认加仓 10%
主升加仓 10%
高位不加仓，只卖出
```

## 9. 卖出模块

卖出分为止损、止盈、趋势退出、时间退出。

### 9.1 止损

触发以下任一情况必须处理：

- 跌破计划止损价。
- 跌破20日线且无法收回。
- 放量破位。
- 买入逻辑消失。
- 板块进入退潮。

### 9.2 止盈

触发以下情况可以分批止盈：

- 到达目标价。
- 连续加速上涨。
- 情绪高潮。
- 高位放量滞涨。
- 涨幅远离均线。

### 9.3 时间退出

买入后 5 到 7 个交易日没有明显上涨，考虑减仓或退出。

### 9.4 分批卖出

```text
第一目标：卖出 1/3，降低风险
第二目标：再卖出 1/3，锁定收益
趋势破坏：卖出剩余仓位
```

## 10. 复盘模块

每笔交易必须归类。

| 类型 | 说明 | 处理 |
| --- | --- | --- |
| 系统内盈利 | 按规则做，结果盈利 | 保留规则 |
| 系统内亏损 | 按规则做，结果亏损 | 接受亏损，继续统计 |
| 系统外盈利 | 违规但赚钱 | 不能强化，记为风险 |
| 系统外亏损 | 违规且亏钱 | 重点修正 |

月度复盘重点：

- 胜率。
- 盈亏比。
- 最大回撤。
- 哪种模式最赚钱。
- 哪种模式最亏钱。
- 违规交易次数。
- 是否追高。
- 是否止损拖延。
- 是否卖飞趋势股。

## 11. 每日执行清单

盘前：

- 判断市场环境评分。
- 判断情绪周期。
- 更新观察池。
- 写好今日计划。

盘中：

- 只执行计划内交易。
- 不临时追高。
- 触发止损就处理。
- 情绪不稳时停止交易。

盘后：

- 记录交易。
- 更新持仓状态。
- 复盘是否违规。
- 写好明日计划。

## 12. 系统使用规则

1. 每天先看 `01_市场环境判断.md`。
2. 选股时用 `02_选股体系.md`。
3. 买入前必须通过 `03_买入规则.md`。
4. 持仓后按 `04_卖出规则.md` 管理。
5. 仓位必须服从 `05_仓位与风险控制.md`。
6. 每天使用 `07_每日交易清单.md`。
7. 每笔交易记录到 `06_复盘模板.md`。
