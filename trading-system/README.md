# 交易系统总纲

本文档把 `1_extracted.md` 中的交易经验整理成一套可执行的交易系统。它不是荐股系统，也不是自动买卖系统，而是一套帮助你判断环境、筛选标的、规划买卖、控制仓位、复盘优化的规则库。

## 核心原则

1. 先判断市场环境，再选择交易模式。
2. 先写交易计划，再决定是否下单。
3. 只做自己能定义买点、卖点、止损位和仓位的交易。
4. 不追高、不满仓、不在亏损中盲目加仓。
5. 盈利加仓，亏损不加仓。
6. 趋势没坏就持有，趋势破坏就退出。
7. 每笔交易都必须复盘，系统靠复盘迭代。

## 推荐交易模式

初版系统优先支持三类模式：

1. 趋势股交易：适合中短期持有，重点看大盘、板块、个股三周期共振。
2. 情绪短线交易：适合高执行力选手，重点看情绪周期、题材强度和止损纪律。
3. ETF 定投或波段：适合上班族和稳健型资金，重点看长期方向、低位分批、牛市退出。

## 一笔交易的标准流程

1. 判断市场环境：多头、空头、震荡、情绪上升、情绪退潮。
2. 确定交易模式：趋势、情绪短线、ETF、空仓等待。
3. 选出候选标的：只进入观察池，不急着买。
4. 等待买点：突破回踩、支撑确认、均线修复、三周期共振。
5. 写下计划：买入价、止损位、目标位、仓位、加仓条件、卖出条件。
6. 执行交易：按计划下单，不临盘改规则。
7. 复盘结果：判断是系统盈利、系统亏损，还是违规操作。

## 不做清单

- 不在没有计划时买入。
- 不因为别人推荐而买入。
- 不在连续大涨后追高重仓。
- 不在下跌破位后幻想解套。
- 不在亏损状态下随意补仓。
- 不在情绪退潮期做高位接力。
- 不把单次盈利当成系统有效。
